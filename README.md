# Rex57's tap

Casks by Rex57, for [nanobrew](https://github.com/justrach/nanobrew) (`nb`).

| Cask | What it is |
|---|---|
| `nanobrew-ui` | [Nanobrew UI](https://github.com/Rex57/nanobrew-ui), an unofficial native macOS app for nanobrew |

Install a cask with nanobrew:

```sh
nb install --cask Rex57/tap/nanobrew-ui
```

Upgrade it with `nb upgrade --cask Rex57/tap/nanobrew-ui`. nb records a tap cask under its full name, so use the
full name; the short name answers "not installed".
